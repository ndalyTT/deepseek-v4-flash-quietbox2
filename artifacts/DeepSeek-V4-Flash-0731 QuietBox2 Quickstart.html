DeepSeek-V4-Flash-0731 QuietBox2 Quickstart Build the exact-architecture mixed-BFP2/BFP4 TTNN deployment and serve the official Hugging Face checkpoint through the Tenstorrent vLLM plugin.

This recipe is intentionally narrow: one request at a time, a complete (4,1) Blackhole mesh, and a 131,072-token deployment context. Pin the checkpoint and repository revisions below. The branch is local until its owner explicitly authorizes GitHub publication.

Why quantization is mandatory. The preserved stock policy requires at least 57,998,069,952 bytes/device, exceeding measured usable DRAM by 24,087,774,400 bytes/device. The selected policy's weights and full cache are resident at 33,389,479,936 bytes/device and leave 520,815,616 bytes/device free. Streaming prefill additionally bounds context-shaped TTNN programs in 8192-token epochs; the resulting policy passed the complete 65536- and 130560-token warmups and measured requests. Routed gate/up is BFP4 only in layers 2, 27, 29, 32, 34, 36, 41, and 42; the other 35 layers use BFP2. Routed down and shared experts use BFP4.

08

Start the OpenAI-compatible server

python_env/bin/vllm serve "$DEEPSEEK_MODEL" \

  --port 8010 \
  --served-model-name deepseek-ai/DeepSeek-V4-Flash-0731 \
  --tokenizer "$DEEPSEEK_MODEL" \
  --tokenizer-mode deepseek_v4 \
  --reasoning-parser deepseek_v4 \
  --trust-remote-code \
  --dtype bfloat16 \
  --max-model-len 131072 \
  --max-num-seqs 1 \
  --max-num-batched-tokens 131072 \
  --block-size 128 \
  --additional-config '{"tt":{"sample_on_device_mode":"all","trace_mode":"all","enable_model_warmup":false,"trace_region_size":268435456,"l1_small_size":2048,"fabric_config":"FABRIC_1D_RING","fabric_reliability_mode":"RELAXED_INIT"}}'

Keep this terminal open. The server is ready only after vLLM reports application startup complete. The qualified run used this contract, but the final post-reboot lifecycle check on this particular host reproduced a device-0 ERISC heartbeat failure before weight loading even after bounded reset/list and a successful standalone 4×1 mesh smoke. 10

Reproduce the latency sweep

Keep the server from step 08 running and execute this client from a second terminal. Never start the offline loader while the server owns the cards.

python_env/bin/python \
  models/autoports/deepseek_ai_deepseek_v4_flash_0731/tools/run_vllm_server_benchmark.py \
  --api-base http://127.0.0.1:8010/v1 \
  --model deepseek-ai/DeepSeek-V4-Flash-0731 \
  --artifact-json /tmp/deepseek-v4-isl-sweep.json \
  --isls 128,1024,4096,8192,16384,32768,65536,130560 \
  --osl 512 \
  --warmup-output-tokens 2

The driver sends exact token-ID prompts, runs one excluded compile warmup per ISL, and atomically checkpoints every completed row. It uses deterministic on-device sampling (temperature=0, top_p=1, top_k=1, seed=0) and enforces exact OSL with ignore_eos; do not add host-only min_tokens. Pass --resume after an interruption; do not reset or restart the healthy server.

Operating limits

What is and is not qualified

  • Qualified now: exact 43-layer/256-expert architecture, batch one, concurrency one, greedy TT on-device sampling, 4×1 mesh, and all requested ISLs through 130,560 with OSL 512. The 131,072-token allocation and runtime contracts both passed.
  • Not qualified: batch greater than one, prefix caching, chunked prefill, host sampling, async decode, speculative decoding, LoRA, data parallelism, or the model card's 1,048,576-token maximum.
  • Do not send response_format or other structured-output constraints. vLLM routes those requests to host sampling, which this on-device-only adapter does not support.
  • The official-Harness Terminal-Bench path is prepared but not scored. It uses max reasoning and a 49,152-token ceiling; OSL 512 applies only to the deployment performance matrix. Its v27 canary is blocked by a repeated pre-weight-load ERISC initialization failure.
  • The final post-reboot server attempt failed on device-0 cores 29-25, 28-25, 24-25, and 22-25 even though list/reset/list and a standalone 4×1 mesh smoke passed. Treat this as current infrastructure recovery work, not a model correctness regression.
  • The first request at a new ISL may compile. Performance rows use one excluded warmup at that same ISL.
  • vLLM 0.25.1 may print a shutdown-only torch.accelerator.empty_cache() traceback on this non-CUDA platform after a successful request. Qualification requires the benchmark wrapper to exit zero and the artifact to say status: passed.
  • Stop the server with Ctrl-C. If a process dies while owning devices, verify no Metal process remains, then reset exactly IDs 0–3 with tt-smi -r 0 1 2 3.
